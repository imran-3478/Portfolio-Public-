Privacy Policy — “n8n” Personal Automation

Last updated: 7 November 2026

“n8n” is a private, single-user automation owned and operated by Imran Akanda for his personal use only. It is not a public service and has no other users. This page explains how the automation handles data, as required for its Google OAuth consent screen.

What the automation does

Once a day, the automation builds a short morning message for its owner containing (1) the local weather forecast and (2) the owner’s calendar events for that day, and sends that message to the owner through Telegram.

Google user data accessed

Through Google OAuth, the automation reads the owner’s Google Calendar events (event titles, times and descriptions) at the moment the daily message is composed. Access is limited to the owner’s own account; the owner is the only person who can sign in.

How the data is used and shared

  • Calendar data is used only to compose the owner’s own daily message. It is never sold, rented, or used for advertising.
  • The composed message (weather + today’s events) is delivered to the owner via the Telegram Bot API. Weather data comes from the public Open-Meteo API; only geographic coordinates are sent to that service.
  • No calendar data is shared with any other third party.

Storage and retention

The automation runs on the owner’s own n8n instance. Calendar data passes through the workflow in memory while a run executes; it is not copied into any separate database or analytics system. Standard execution logs are retained only for troubleshooting the automation itself.

Revoking access

Access can be revoked at any time from the Google Account permissions page: myaccount.google.com/permissions. Revoking access stops the automation from reading calendar data immediately.
