Database Engineering

How your app's data really works. PostgreSQL stores it permanently in structured tables — ACID transactions guarantee critical operations never half-complete. Stored procedures & views run complex logic inside the database itself, eliminating slow round-trips. Redis keeps hot data (sessions, live locations) in RAM for millisecond responses, with TTL auto-expiry. Production setup adds Linux/VPS hosting, automated backup & restore, replication for zero downtime, and query performance tuning. I build on this stack every day — CNG Ride and GushKhor both run on Supabase (PostgreSQL).
